### **Guppy Language "Constitution" (Strict Compliance Required)**

**1. Determinism & Control Flow Rules**

- **Absolute Determinism:** No random imports. Output must be reproducible.
    
- **`@guppy` Functions (Runtime Logic):**
    
    - **Allowed:** You **MAY** branch conditionally on results derived from non-destructive measurements.
        
    - **Allowed:** You **MAY** branch on classical function arguments (runtime values).
        
- **`@guppy.comptime` Functions (Compile-Time Logic):**
    
    - **Strict Prohibition:** You **MUST NOT** branch on function arguments, measurement outcomes, or hardcoded constants. Treat arguments here as symbolic variables.
        
- **Looping:** Loop ranges must use hardcoded integer literals, never variable arguments.
    

**2. The Decorator Decision Tree**

- **Use `@guppy.comptime` IF:** The function uses `pi` **OR** is purely linear (no control flow).
    
- **Use `@guppy` IF:** The function contains control flow **AND** does **not** use `pi`.
    
- **Constraint:** A function decorated with `@guppy` CANNOT use any variable named `pi`.
    

**3. Argument Passing Syntax & Data Structures**

- **Inside `@guppy` functions:**
    
    - **ILLEGAL:** Constructing arrays directly within the function call parameters.
        
    - **FIX:** You **MUST** pass a pre-existing, named array variable.
        
- **Inside `@guppy.comptime` functions:**
    
    - **LEGAL:** You may construct a temporary list of qubits using square brackets to pass as an array argument.
        

**4. Qubit Lifecycle: "Borrowed" vs. "Owned" (Common Source of Errors)**

- **Borrowed Qubits (Arguments):**
    
    - **Rule:** DO NOT measure these destructively.
        
    - **Allowed:** Non-destructive measure and reset (keeps the qubit alive).
        
- **Owned Qubits (Local Variables):**
    
    - **Creation:** Must be fresh. **Never** include existing variables in a new array definition. No aliasing allowed.
        
    - **Forbidden Syntax:**
        
        - `qreg1 = array(qubit1, qreg0[0])` _(ILLEGAL: qubit1 is already defined)_
            
        - `q_new = qubit_old` _(ILLEGAL: No aliasing allowed)_
            
    - **Allowed Syntax (Generators Only):**
        
        - `qreg1 = array(qubit() for _ in range(2))` _(VALID: Creates fresh instances)_
            
        - `qubit1 = qubit()` _(VALID: Defining single qubits)_
            
        - `num_qubits = 4; qreg0 = array(qubit() for _ in range(num_qubits))` _(VALID: Register with hardcoded ints)_
            
    - **Allocation Limit:** You must limit the amount of new qubits declared in each function scope such that the total amount of new qubits allocated throughout all functions combined does not exceed 15.
        
    - **Cleanup:** You **MUST** consume these before the function scope ends using a destructive single or array measurement. Non-destructive measurements do _not_ satisfy this requirement as they keep the qubit alive.
        

**5. Measurement Strictness & Typing (STRICT ENFORCEMENT)**

- **`measure`**: Destructive. Valid ONLY on standalone qubit variables. **ILLEGAL** on array elements. Returns a boolean.
    
- **`measure_array`**: Destructive. Valid ONLY on a full qubit array. Returns an array of booleans.
    
- **`measure_and_reset`**: Non-destructive. Valid on standalone qubits OR array elements. Returns a boolean.
    
- **Typing Rules for Measurements:**
    
    - Measurements return booleans, **NOT integers**.
        
    - **No Math:** You **MUST NOT** perform arithmetic on measurements.
        
    - **No Integer Comparison:** You **MUST NOT** compare booleans to integers. Use standard boolean evaluation.
        
    - **Helper Type Hints:** If passing a measurement to a helper function, the argument MUST be type-hinted as a boolean.
        

**6. Main Function Requirements**

- **Signature:** Must accept external qubits as arguments.
    
- **Prohibitions:**
    
    - No internal qubit definitions (all qubits must be passed in).
        
    - No destructive measurements (all qubits are borrowed).
        
    - No compile method calls at the end of the script.
        

**7. Gate & Argument Uniqueness (No Double Borrowing)**

- **Singular Targets:** Standard quantum gates accept individual qubit objects, **NOT** arrays or lists. To apply a gate to an array element, explicitly index it.
    
- **Uniqueness:** For any multi-qubit gate or function call, you **MUST NOT** pass or borrow the same qubit variable twice. The arguments must be distinct physical qubits.
    
- **Angles:** Rotations require their numerical values to be wrapped in an angle type. For gates taking both qubits and angles, the angle is always the final argument.
    

**8. Array Indexing Rules (STRICT ENFORCEMENT)**

- **Prohibition:** Indexing a qubit array with runtime-evaluated variables is **PROHIBITED**. You **MUST ONLY** use integer literals for indices.
