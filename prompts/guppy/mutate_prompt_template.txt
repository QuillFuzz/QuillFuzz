### **Strict Constraints (Violation = Compilation Failure)**

**1. Decorator & Pi Logic (The "Constitution")**

- **`@guppy.comptime`**: Must be used if the function uses **`pi`** (even via `math.pi`) OR is purely linear (contains no control flow).
    
- **`@guppy`**: Must be used if the function contains runtime control flow (branching on measurement).
    
- **The Conflict Rule**: A function decorated with `@guppy` **CANNOT** use `pi`. If you switch a function to `@guppy` to add branching, you must ensure it does not use `pi`.
    

**2. Strictly Permitted Control Flow & Typing**

- **Allowed:** Branching on measurement results **ONLY** inside `@guppy` functions.
    
- **Allowed:** Loops with hardcoded integer literals.
    
- **FORBIDDEN:** Branching on function arguments. Arguments are symbolic/runtime values.
    
- **FORBIDDEN:** Branching on measurement results inside `@guppy.comptime`.
    
- **Strict Typing:** Booleans cannot be equated with integers. Use standard boolean evaluation.
    

**3. Function Call & Array Passing (CRITICAL)**

- **Inside `@guppy` functions:** You **CANNOT** construct arrays/lists directly within the function call parameters. You **MUST** pass a pre-existing, named array variable.
    
- **Inside `@guppy.comptime` functions:** You **ARE ALLOWED** to construct temporary lists using Python list syntax `[]` directly in the function call.
    

**4. Array Indexing Rules (STRICT ENFORCEMENT)**

- **Literal Indices Only:** Indexing a qubit array with runtime-evaluated variables (like loop counters) is **PROHIBITED**. You **MUST ONLY** use integer literals for indices.
    

**5. Gate & Qubit Uniqueness & Allocation Limits**

- **Distinct Arguments:** For multi-qubit gates or function calls, the arguments must be distinct physical qubits (no double borrowing).
    
- **Fresh Instantiation:** New arrays must contain newly instantiated qubits, not existing variables or array elements. These are "owned" qubits and must be measured.
    
    - **Forbidden Syntax:** `qreg1 = array(qubit1, qreg0[0])` _(ILLEGAL: qubit1 is already defined)_ | `q_new = qubit_old` _(ILLEGAL: No aliasing allowed)_
        
    - **Allowed Syntax (Generators Only):** `qreg1 = array(qubit() for _ in range(2))` _(VALID: Creates fresh instances)_ | `qubit1 = qubit()` _(VALID: Defining single qubits)_ | `num_qubits = 4; qreg0 = array(qubit() for _ in range(num_qubits))` _(VALID: Register with hardcoded ints)_
        
- **Qubit Allocation Limit:** You must limit the amount of new qubits declared in each function scope such that the total amount of new qubits allocated throughout all functions combined does not exceed 15.
    

**6. Measurement Rules**

- **Destructive Single Measure:** Standalone qubits only. Consumes the qubit.
    
- **Destructive Array Measure:** Full registers only. Consumes the entire register.
    
- **Non-destructive Measure and Reset:** Standalone qubits or specific array elements. Keeps the qubit alive.
    
- **ILLEGAL:** You cannot use the standard destructive single measurement on array elements.
    

**7. Main Function Restrictions**

- If you mutate the main function (which acts as the entry point for external borrowed qubits), you **MUST NOT** instantiate new internal qubits inside it.
    
- You **MUST NOT** destructively measure borrowed qubits in the main function. Non-destructive measurements are allowed.
