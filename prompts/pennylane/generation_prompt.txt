**Objective:** Generate complex, valid, and deterministic PennyLane code for a compiler fuzzing campaign.

### Strict Output Rules

- **Imports:** The code must begin with the exact imports required: `import pennylane as qml` and optionally `import numpy as np`. No other imports are allowed.
- **Pure Python:** Output raw code only. No markdown blocks (```), no intro/outro text, and no comments outside the code.
- **Style:** Use 4-space indentation.
- **Scope:** Stop immediately after defining `main()`. DO NOT add execution guards (`if __name__ == "__main__":`), function calls, or print statements.

### Architectural Constraints

- **Determinism:** Logic must be deterministic (no `random` module). Use loop indices or constants for variability.
- **No Undefined Methods:** Only use methods that actually exist in PennyLane:
    - **Gate operations:** `qml.PauliX`, `qml.PauliY`, `qml.PauliZ`, `qml.Hadamard`, `qml.CNOT`, `qml.RX`, `qml.RY`, `qml.RZ`, `qml.CRX`, `qml.Toffoli`, etc.
    - **Measurement:** `qml.expval`, `qml.probs`, `qml.state`, `qml.sample`, `qml.var` applied to observables like `qml.PauliZ`, `qml.PauliY`, etc.
    - **Measurement Constraints (IMPORTANT):**
      - `qml.expval(observable)` and `qml.var(observable)` work with any device.
      - `qml.probs(wires=[...])` or `qml.probs(op=...)` works with any device.
      - `qml.sample()` **without** an observable (e.g., `qml.sample()` or `qml.sample(wires=[...])`) works with any device for basis measurement.
      - `qml.sample(observable)` **with an observable** (e.g., `qml.sample(qml.PauliZ(0))`) requires a device with shots enabled (e.g., `qml.device('default.qubit', wires=n, shots=1000)`).
      - **Recommended:** Use `qml.expval()` for expectation values, `qml.probs()` for probability distributions, and plain `qml.sample()` for bit sampling. Avoid `qml.sample(observable)` unless you are sure shots are enabled.
- **Parametric gate arguments:** For parameterized gates (e.g. `qml.RX`), the angle is the first positional argument, the target wires are specified via the `wires` keyword argument. Example: `qml.RX(0.5, wires=0)`.
  - **Important:** Circuit function parameters will be passed as **numpy arrays**, not scalars. If you need a scalar angle, extract it from the array (e.g., `x[0]` if `x` is a numpy array). If indexing, always check bounds or use modulo to handle variable array sizes.
  - Example: `def circuit(x): ... qml.RX(x[0], wires=0)` where `x` is a numpy array.

#### Helper Functions (Modular Logic)

- **Initialization:** Helper functions should be standard Python functions containing PennyLane quantum operations. They are NOT decorated with `@qml.qnode(...)`.
- **Composition:** They can accept wire labels and parameters as inputs and apply operations.
- **Flow & Conditionals:** May contain classical flow control (`if` statements, `for` loops). Do not use mid-circuit measure conditions if not fully supported without specific plugins. Keep logic dependent on classical inputs instead.

#### Main Function (Global Logic)

- **Initialization:** Define a device within `main`, e.g. `dev = qml.device('default.qubit', wires=num_wires, shots=1000)`.
  - **IMPORTANT: Always include `shots=1000` (or similar) when creating the device.** This enables sampling-based measurements and is required for differential testing.
- **Quantum Node Definition:** Define a quantum function (e.g., `def circuit(x): ...`) and wrap it with a QNode explicitly `qnode = qml.QNode(circuit, dev)` or use the decorator within `main()`.
- **Parameters:** Circuit function parameters will be passed as **numpy arrays** during execution. If you index into them (e.g., `x[i]`), ensure the code handles potential index errors gracefully (e.g., use `x[i % len(x)]` or check bounds).
- **Calling Helpers:** Inside the quantum function, call previously defined helper functions directly, passing parameters or extracted values as needed.
- **Measurement Return:** The quantum function must return one or more measurements at the very end, e.g., `return qml.expval(qml.PauliZ(0)), qml.probs(wires=[1, 2])`.
- **Return:** The `main()` function must return the `QNode` object.
